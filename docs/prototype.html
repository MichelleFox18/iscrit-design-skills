Развитие с понятным следующим шагом

Три варианта для внутренней платформы дизайн-команды. Выберите направление, чтобы посмотреть его цвета на схемах ниже.

Выбрано для просмотра: Студия. Выбор здесь меняет только схему; направление проекта согласуется в чате.

Это предварительные схемы, а не работающая платформа. Названия компетенций и описания уровней появятся после импорта исходной таблицы. Числовые результаты сотрудников здесь не показаны.

Карта интерфейса

Публично: о платформе → матрица → карточка компетенции → треки → внешние материалы.

После входа: мой обзор → оценка → развитие → история → материалы. Руководителю доступна команда; администратору — управление.
