# Дизайн-система

Утверждено направление «Студия», уточнённое тремя пользовательскими референсами.
Реализация — `src/app/globals.css` и общие компоненты `src/components/`.

| Токен | Значение | Применение |
| --- | --- | --- |
| White | #FFFFFF | Основной фон, кнопки на синем первом экране |
| Sky Blue | #D0E6FF | Логотип, главный следующий шаг, описания уровней |
| Purple | #453C69 | Навигация, основные кнопки и акценты |
| Orange | #ED8D48 | Детали геометрии и смысловые акценты |
| Ink | #343243 | Основной текст |
| Muted | #646174 | Пояснения, подписи |
| Tile | #F4F4F6 | Прямоугольные карточки и плашки разделов |

Цвета взяты из HEX-подписей референса. Подписи RGB на изображении
местами не соответствуют HEX; их не использовали как независимые значения.

Типографика: Arial/Helvetica, обычное начертание крупных заголовков,
умеренное отрицательное межбуквенное расстояние. Рабочие тексты 14–16px;
крупные экранные заголовки 34–92px в зависимости от ширины.
Все страницы используют общий базовый CSS, формы, кнопки и сообщения.

Главная: белая шапка, синий первый экран, оригинальная SVG-геометрия с
полупрозрачными и золотыми гранями, светлые кнопки-пилюли, название внизу
слева. SVG не является импортированным оригинальным 3D-рендером бренда.
Ниже — прямоугольная сетка 2/2 и 2/1/1, информация и процесс review.

Рабочие страницы: спокойный белый фон, боковая навигация, светлая
прямоугольная плашка названия. Кабинеты используют ту же палитру и
простые блоки без декоративной графики за длинными описаниями уровней.

Скругление: 40px для кнопок и маленьких статусов; 0–3px для основных
блоков и полей. Карточки не превращаются в отдельную визуальную систему.
SVG-иконки Lucide используются для навигации и основных направлений.

Адаптация: 760px — вертикальная мобильная структура; меню раскрывается
явно и включает выход. Три автора оценки на узких экранах размещаются
последовательно. Длинные описания остаются под выбранным уровнем.

Доступность: skip-link, семантические заголовки, labels, aria-current,
aria-pressed, текстовые статусы, видимый фокус, минимальная высота
основных интерактивных элементов 44px, обработка prefers-reduced-motion.
Цвет никогда не заменяет подпись. Полный аудит WCAG AA ещё требуется.

Предыдущий `prototype.html` сохранён как документ этапа выбора;
актуальный интерфейс реализован в Next.js.
