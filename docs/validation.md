# Проверка предварительных материалов

В этой итерации проверен только документальный HTML-прототип.

- Chromium через Playwright: переключение трёх визуальных тем работает.
- Состояние выбранной темы отражено в `aria-pressed` и текстовом статусе.
- Выбор Н/П сохраняет пояснение об исключении ответа из среднего.
- На ширинах 1440, 768 и 390px нет горизонтального переполнения страницы.
- При выполнении сценариев нет ошибок JavaScript.
- `git diff --check` не выявил проблем; исходный README не изменён.

Среда использует системный `/usr/bin/chromium`; комплект браузеров Playwright
не установлен. Прототип загружался через `page.set_content`, поскольку
браузерная политика блокирует `file://`-навигацию. Внешних ресурсов у файла нет.

Не проверены и ещё не реализованы: рабочая авторизация, RLS, база данных,
формулы, импорт матрицы, все состояния review, история и работающие кабинеты.
Проверка адаптивной схемы не подтверждает полное соответствие WCAG AA.
MVP не считается готовым: требуются исходная книга и согласование направления.
